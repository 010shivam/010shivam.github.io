ADD AN ARTICLE
1. Copy notes/_TEMPLATE.txt, rename it e.g. 2026-11-09-my-topic.md (lowercase, hyphens, no spaces).
2. Fill in title, date, tag, summary, pdf, then write the executive summary under the --- line.
3. Put the PDF in notes/pdfs/ with the exact name used on the pdf: line.
4. Push. The notes list updates itself (GitHub Action). Without GitHub, run: python3 tools/update-notes.py

EDIT HOME / CONTACT: content/home.txt and content/contact.txt. Photo goes in images/.
